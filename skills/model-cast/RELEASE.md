# T15 source development snapshot

Public source only; not a new tagged release or a claim of final visual acceptance.
The Python runtime and fixed workflow prompts are exported from the reviewed T15 baseline without implementation changes. Private handoffs and actual runs are not included.

The V3 package builder and pinned Lookset exporter validate structure and byte provenance. User acceptance and image quality remain separate. macOS `sips`, available system CJK fonts, Python and Pillow are required for the full workflow. Codex CLI 0.161.0 is the pinned generation baseline; validate another version before use. No images were generated to prepare this public snapshot.
