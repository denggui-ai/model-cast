# 模特完整 AI 资料库｜一次多选上传

本文件夹适用于 ChatGPT 和 Codex 的普通 AI 使用路线。请在新对话中打开本文件夹，选中全部图片及本说明、`asset-index.json`，一次多选上传。然后发送：

> 请先阅读 START-HERE.md 和 asset-index.json，识别模特身份及所有视觉参考。以后根据我的自然语言任务，自主选择最少且相关的身份、角度和动作参考；不要改变模特身份。告诉我你实际选择了哪些文件。不要把 N2 人偶图当作模特，也不要把所有图片无差别传给图像工具。

## 资料怎么分工

- `01`：主要面部身份锚点。
- `04`：主要正面全身和身体比例锚点。
- `06`、`07`：侧面和背面身体参考；背面看不到脸，不能证明面部身份。
- 其余 `02`、`03`、`05`、`08`–`12`：按任务选择的补充角度；没有脸的图片不能作为面部身份证据。
- `13`–`15`：行走、坐姿、自然微笑的已确认示例，只在任务相关时使用。
- `16`：N2 灰色无脸人偶相机角度／景别指南。它不是模特身份、不是姿势线稿、不是服装图，也不是图像编辑底图。

## 使用边界

1. 先用 `asset-index.json` 和图片内容识别文件，再根据用户任务选择最少必要参考；文件名只是辅助标签。
2. 新姿势通常优先选择 `01` 加一张最相关的身体／角度参考。动作任务可按需加入 `13` 或 `14`；表情任务可按需加入 `15`。
3. N2 `16` 只用于理解镜头方向和取景范围。不要让它替代真实模特图。
4. 能阅读或选择附件，不代表下游图像生成／编辑工具一定收到这些图片。执行图像任务前，必须确认所选图片确实作为参考传给工具；如果宿主不能传递，请明确告诉用户并请求直接补传所需图片。
5. 不要声称人物姿势线稿已经包含在本版本中；当前没有交付 C10 线稿。
6. 本资料库用于模特身份和视觉参考，不负责服装设计、商品换装或商业拍摄流程。商品和服装事实由用户另行提供；Lookset 用户应使用独立 D2 适配包。
