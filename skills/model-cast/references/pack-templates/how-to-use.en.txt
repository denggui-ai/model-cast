Yuning AI Model — User Guide

model-cast creates an original AI model and delivers her visual reference assets. This library is for continuing to use the model in ChatGPT or Codex. Later garment try-on, clothing design, and commercial photography are handled by downstream tools you choose; they are not functions of model-cast itself.

[Recommended: upload all files together]
1. Open the folder “4_AI_Model_Library_MultiUpload”.
2. Select all files and drag them into a ChatGPT conversation. Codex users can place the whole folder in their workspace.
3. Send:
   “Read START-HERE.md and asset-index.json first. Understand Yuning’s identity and visual references. For each natural-language task, choose the smallest relevant reference set and tell me which files you actually selected. Preserve her identity and do not treat the N2 mannequin as the model.”
4. Then describe your task, for example:
   - “Create a full-body side-view studio reference of Yuning.”
   - “Use her walking example as a guide for a natural full-body walking image.”
   - “Create a head-and-shoulders portrait while preserving her face identity and hairstyle.”

[What the files are for]
- 01: primary face identity reference.
- 04: primary front full-body and body-proportion reference.
- 06 and 07: side/back body references; 07 has no visible face and cannot prove facial identity.
- 02, 03, 05, 08–12: supplementary angles, selected only when relevant.
- 13–15: walking, sitting, and natural-smile examples; use only when relevant.
- 16: N2 grey faceless mannequin showing camera direction and framing only. It is not Yuning, not a pose drawing, not a clothing image, and not an image-edit base.

The folder “2_Upload_to_AI” retains the four core images (01, 04, 06, 07) for simple tasks that need a minimal reference set. Prefer the complete library for multi-reference use.

[Important limitations]
- Reading and selecting attachments does not prove that an image-generation/editing tool received them. Before executing an image task, confirm that the AI states which references were actually passed to the tool. If the host cannot pass the selected images, attach the required images directly as requested.
- Filenames are labels; identify images using both asset-index.json and visual content.
- C10 human-pose line art is not implemented and is not included.
- Do not treat N2 as identity reference or use images without a face as facial-identity evidence.
- Garment try-on, clothing design, and commercial photography are outside model-cast. Lookset users should use the separate Lookset D2 adapter and must not mix N2 into D2.

[After generation]
Check that Yuning remains recognizable and that facial memory points, hairstyle, and body proportions have not drifted. Angle references help only for their corresponding views; a back view or faceless image cannot prove facial identity. If the result is unstable, restart from 01 plus the most relevant angle rather than using an unstable output as the new identity anchor.
