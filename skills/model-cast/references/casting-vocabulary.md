# C12 一页选角词表

仅作原创成年女性的可见结构描述，不读取或引用 raw 镜像库，不按出现频率推荐。成熟度与不同脸型同等考虑；成熟度指视觉观感，不据脸推定真实年龄。每位至少组合两项结构差异。

| 维度 | 词 | 对照说明 |
|---|---|---|
| 脸的长宽 | 长窄脸 | 和短宽脸相比，长窄脸的纵向长度相对横向宽度更明显。 |
| 脸的长宽 | 短宽脸 | 和长窄脸相比，短宽脸的横向占比更大，面中到下巴的纵向距离观感更短。 |
| 脸的长宽 | 椭圆脸 | 和方脸相比，椭圆脸的脸侧向下巴连续收窄，转折更圆缓。 |
| 脸的长宽 | 圆脸 | 和长椭圆脸相比，圆脸的长宽更接近，脸侧弧线更饱满。 |
| 下颌 | 方下颌 | 和圆缓下颌相比，方下颌在下颌角处有明确转折，下脸横向支撑更明显。 |
| 下颌 | 圆缓下颌 | 和方下颌相比，圆缓下颌从耳下至下巴的过渡更柔和。 |
| 下颌 | 收窄下颌 | 和宽下颌相比，收窄下颌向下巴的两侧明显内收。 |
| 下颌 | 宽下颌 | 和收窄下颌相比，宽下颌的两侧在接近下巴处仍保有较大间距。 |
| 颧骨 | 横向外展颧骨 | 和内收颧骨相比，横向外展颧骨在脸侧形成更明确的宽度与轮廓转折。 |
| 颧骨 | 内收颧骨 | 和横向外展颧骨相比，内收颧骨较少向脸侧突出，外轮廓更连贯。 |
| 颧骨 | 高位颧骨 | 和低位颧骨相比，高位颧骨的可见支撑点更接近眼下。 |
| 颧骨 | 低位颧骨 | 和高位颧骨相比，低位颧骨的可见支撑点更靠面颊中部。 |
| 眉眼 | 平直眉配细长眼 | 和弧眉配圆眼相比，平直眉配细长眼的横向线条更突出、眼裂纵向开度更小。 |
| 眉眼 | 弧眉配圆眼 | 和平直眉配细长眼相比，弧眉配圆眼的眉部曲线更明显、眼裂纵向开度更大。 |
| 眉眼 | 近眉眼间距 | 和宽眉眼间距相比，近眉眼间距的眉下缘与上眼睑之间留白更少。 |
| 眉眼 | 宽眉眼间距 | 和近眉眼间距相比，宽眉眼间距的眉眼之间留白更多。 |
| 鼻唇 | 窄鼻翼配薄唇 | 和宽鼻翼配饱满唇相比，窄鼻翼配薄唇的鼻翼横向跨度更小、唇红厚度更薄。 |
| 鼻唇 | 宽鼻翼配饱满唇 | 和窄鼻翼配薄唇相比，宽鼻翼配饱满唇的鼻翼跨度更大、唇红更厚。 |
| 鼻唇 | 明显唇峰 | 和圆缓唇峰相比，明显唇峰的上唇中部双峰与凹口边界更清楚。 |
| 鼻唇 | 圆缓唇峰 | 和明显唇峰相比，圆缓唇峰的上唇中部起伏更平缓。 |
| 成熟度 | 青年成人感 | 和成熟成人感相比，青年成人感可用更饱满的面颊、更柔和的骨肉过渡表达，不做未成年化。 |
| 成熟度 | 成熟成人感 | 和青年成人感相比，成熟成人感可用更清晰的骨肉转折、适量自然表情纹表达，不仅靠浓妆。 |
| 成熟度 | 熟龄成人感 | 和成熟成人感相比，熟龄成人感保留更多自然面部纹理与年龄痕迹，不磨皮回春。 |

发型另列：和贴头直发相比，蓬松卷发的发丝弯曲和外轮廓体积更明显；和中分相比，侧分的分缝偏向一侧。发型会遮挡脸侧，比较结构时须排除遮挡影响。

妆容另列：和浓妆相比，淡妆保留更多皮肤纹理、眉眼唇自然边界；和强修容相比，轻修容较少人为改变颧骨和下颌的明暗边界。
