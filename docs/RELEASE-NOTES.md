# Public project release notes

## v0.2.0 — 2026-11-08

This is the first formal release following the historical `v0.1.0-beta.1` prerelease. It includes PR #3: the bilingual ordinary-AI multi-file visual library workflow, Yuning showcase, and selectively integrated face-casting guidance/Evals 19–23. The seller-package format remains V3.0 and is distinct from the software version.

The release does not include C10 pose line art. N2 remains a grey mannequin camera/framing guide. Codex multi-file end-to-end behavior, reliable image-tool reference handoff across hosts, fine local facial editing, garment fidelity, and the complete Lookset commercial workflow are not claimed as verified.

## Current public main

The public `main` branch includes the sanitized T15 V3 direct-upload source snapshot and the project-adapted Development Protocol. It now documents the product as an original AI model creation and visual-asset handoff Skill, not a garment try-on or commercial photography tool.

The ordinary ChatGPT/Codex path provides a multi-file visual library: 12 model views, three action/expression examples, N2 camera/framing guide, `START-HERE.md`, and `asset-index.json`. The four core identity images remain available as a lightweight set. The Lookset D2 adapter remains separate.

The Yuning showcase uses Owner-authorized AI-generated project images. README claims distinguish generated assets, Owner acceptance, structural validation, and actual downstream image tests. C10 pose line art is not implemented. The face-casting design guide and Evals 19–23 have been selectively integrated from V0.2. The older V0.2 branch remains separate; its practical nose-tip target was not accepted and it has not been merged wholesale.

## Validation limits

ChatGPT recognized all 16 visual assets in the direct multi-file test. One full-body side-view generation test produced a plausible result, but did not prove that both selected references independently controlled identity. Codex local-folder end-to-end behavior remains unverified. No claim is made that image-tool reference handoff works identically across hosts.

The v0.2.0 tag and GitHub Release identify the formal source release. The owner-specific V3.0 seller package is not included as a public Release attachment in this source-only release.
