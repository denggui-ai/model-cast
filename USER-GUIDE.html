先试一句话

用 $model-cast 帮我设计一位给通勤女装拍图的成年虚拟模特，先聊人物方向，不生成图片。

预期：一个简短、可执行的人物方向，必要时询问影响选角的关键条件。不会生成图片，不需要商品照片。这个文字冒烟测试不证明平台已自动触发技能；请另查技能列表。

可以做什么

  • 把用途、气质或自然语言修改意见整理成人物方向。
  • 从文字创建一位虚构成年人的正脸或正面全身候选，或直接保存已有 AI 原图。
  • 保留原始身份、造型锁、可调范围、接受记录与补充表现。
  • 使用 Lina、Jun 两位 CC0 公共种子，并向裁光交付标准人物包。

model-cast 管人物，裁光 · Caiguang管真实商品拍摄。当前接入使用裁光已有接口，无需修改其代码。

能力边界

不保证跨商品稳定锁脸、任意文字一次命中、精确年龄与尺码、商品全项保真或商业验收。图片均是 AI 虚构成年人，不保证与现实人物绝不相似。公共卡片的年龄、地区、肤色标签和身高是设计描述。

真人服饰任务交给裁光；本入口不将真人照片转成公共 AI 种子。没有自动生图 API、自动重抽、批量阵容扩充或后台持续运行。当前首发是源码预发布，未上架插件市场。

输入用途
人物需求创建时必需；日常语言即可，助手建议与用户要求分开记录。

哪些动作会产生调用

模式行为与成本
讨论 / 选人文字工作与本地参考读取；AI 对话本身仍受宿主账户政策约束。
准备 / 保存本地校验与文件复制，不调用生成服务，不自动公开。
生成 / 修改本次授权内，一位人物的一张候选；原生 image_gen 会发送提示词与所选参考，可能消耗账户额度。失败或未知返回先恢复，不自动重抽。
商品复用裁光独立读取人物包和商品素材，按本次拍摄授权生成并验收。

确认方向、预检通过、预算池有余额，都不自动等于生成授权。继续使用已有明确授权，不重复索取同一许可。发布、安装与分享各按其实际任务授权执行。

核验、安装与发现

  1. 从 GitHub 预发布页获取源码并核对标签。展开到一个新的目录；打开本指南与 README。
  2. 在源码目录运行 shasum -a 256 -c SHA256SUMS（macOS）或 sha256sum -c SHA256SUMS（Linux）。文件校验值只在其来源可信时帮助发现损坏或替换，不能单独认证发布者。
  3. 先按 裁光自己的安装指南安装 beta.18。model-cast 不包含或自动安装它。
  4. 确认 Python 可 import PIL。若缺失，先由你选择或授权配置专用环境；不要绕过图片解码检查。源码中的 requirements 文件供环境配置使用，不会自动执行。
  5. 按 README 安装命令只复制 skills/model-cast 到 ~/.agents/skills/model-cast。已有目录时命令会停止，先备份再替换。也检查旧版是否存在于 ~/.codex/skills 或项目内，避免同名重复。
  6. 打开新聊天，查看本地技能列表中的 model-cast。更改通常自动发现，未出现时重启 Codex；然后运行上方文字测试。发现结果与业务测试分开检查。

安装只添加该技能目录，不改变全局配置、账户、裁光或已有任务。该位置依据 OpenAI 本地技能文档；本次发布没有执行你的本机安装。

开发者的本地冒烟

python3 skills/model-cast/scripts/private_model.py --help

预期列出 prepare、reserve、returned、failed、save，不生成或联网。完整离线契约测试见 README；合成色块由测试生成，不需要用户图片。带裁光接口的用例只有设置实际目录才会运行。

常用说法

  • “按这个方向生成一张候选，我看后再保存。”——一次生成，展示真实候选后等待接受。
  • “脸可以，只把头发改长，妆容淡一点。”——保留身份和其余条件，另存修改候选。
  • “这张 AI 原图我已经接受，保存为我的私人模特。”——核对范围和来源后零生图保存。
  • “没有裁光，只想先聊方向。”——继续文字工作；保存与生成缺依赖时标记 blocked。
  • “这是人物包，用这件商品拍一张。”——转交裁光，重新核对商品与本次图片结果。

文字方案认可不等于接受图片。一次整体接受可覆盖已展示的范围，不强迫逐条签字。

数据放在哪里

本地脚本不联网、无遥测、无后台上传。原始参考被复制进你指定的私人任务目录，候选、request.json、ledger.json、确认记录和 package 保留在那里；request 可能包含绝对路径与私人提示词。目录内 .gitignore 忽略所有内容，但不代替设备权限、加密或备份保护。代码只阻止写入运行技能目录；在源码目录中使用时，仍需把私人任务放到整个源码仓库之外，不能依赖代码自动识别所有相邻目录。

在 Codex 中进行对话和读取文件仍受宿主数据政策约束。真正调用原生生图时，提示词及选中的参考会交给 OpenAI 宿主服务；本项目不直接指定额外外部端点，不增加第三方生成服务或密钥配置。账户费用、缓存和服务端留存遵循宿主政策，本项目无法删除它们。

本地输出默认保留，无自动过期。需要删除时，先保留仍需复用的人物包，再通过文件管理器删除对应私人任务目录；宿主生成缓存和聊天记录需在宿主中另行处理。卸载技能不会清除这些私人产物。公共种子仍保留 CC0，私人保存不授予 CC0 或独家权利。

升级、回退与卸载

先保存进行中的任务和人物包。升级前将现有技能目录完整复制到技能发现目录之外的备份位置，再移走旧目录并安装已核验的新版本。不要在旧目录上覆盖混合文件。此版本没有自动迁移；新版本的包兼容性需单独验证。

回退时移走新版，恢复旧版备份，重新打开聊天并做发现与文字测试。卸载时只删除安装的 model-cast 技能目录并重启客户端。私人任务、人物包、源码下载目录、Python 环境和宿主缓存都保留；按各自用途单独清理。

升级、回退、卸载的完整真实客户端生命周期尚未实测；以上是操作说明，不是已验证兼容性承诺。

遇到问题

  • 找不到技能：核对目录层级，里面应直接有 SKILL.md；检查同名旧安装，再重启。
  • 缺裁光接口：--threadtruth 指向实际含 scripts/model_reference.py 的技能目录，不是插件容器的父目录；当前验证版本为 beta.18。
  • 图片解码失败：保留原文件并检查格式；不允许截断数据、改后缀冒充格式或跳过校验。
  • 调用结果未知：查看本次 request 和账本，先找同次原始返回，不清零重抽。
  • 文件存在或包冲突：另建任务目录；原始身份与旧版包保持不变。

分享诊断时仅提供版本、操作系统、Python/Pillow 版本、失败命令的参数名与脱敏错误。删除密钥、账户 ID、主目录细节、私人提示词、图片内容和原始响应。不要为了排查读取或粘贴 .env；意外暴露的密钥应撤销更换。
